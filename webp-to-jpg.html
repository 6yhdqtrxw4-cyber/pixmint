FAQ

What happens to transparent backgrounds?

JPG doesn't support transparency, so transparent areas are flattened onto white. If you need to keep transparency, convert to PNG instead.

Which quality setting should I use?

92% is visually indistinguishable from the original for most photos. Drop to 80% for noticeably smaller files; go below 60% only when file size matters more than detail.

Is there a file size or count limit?

No hard limit — only your device's memory. Batches of dozens of images are fine on modern hardware.

Does it work on my phone?

Yes — any modern mobile browser (Chrome, Safari, Firefox) can run the conversion locally.

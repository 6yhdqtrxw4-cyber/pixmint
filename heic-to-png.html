Why convert HEIC to PNG on-device?

FAQ

Why is the PNG so much bigger than the HEIC?

HEIC is a modern, highly efficient codec; PNG is lossless but old. Expect PNGs to be 4–5x larger than the source HEIC. If file size matters more than perfect fidelity, use HEIC to JPG instead.

HEIC vs PNG — which should I keep?

Keep HEIC for storage (half the size at the same visual quality); use PNG when you need compatibility with tools that don't support HEIC, or when you need a lossless master for editing.

Does it work on Windows?

Yes — any modern browser on any OS. The decoding happens in the browser, so no HEIC codec needs to be installed on the system.

Is there a file count limit?

No hard limit — only your device's memory. Large batches work fine on modern phones and laptops.
